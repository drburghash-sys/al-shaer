# الشاعر

تطبيق PWA عربي لتدريب كتابة الشعر الفصيح والشعبي في مسار واحد.

## منهج التطبيق
السمع → المعنى → الصورة → اللغة → القافية → الوزن → النقد وإعادة الصياغة.

## الخصائص
- مسار فصيح / شعبي / مشترك.
- تدريب يومي 15 دقيقة وبرنامج 90 يومًا.
- صانع الصورة الشعرية.
- البلاغة التطبيقية.
- تحويل النثر إلى شعر على أربع مراحل.
- دليل أوزان للفصيح وبعض أشهر أوزان النبطي.
- دفتر لغة شخصي.
- حفظ القصائد والمسودات محليًا.
- PWA قابلة للتثبيت وتعمل دون اتصال بعد أول تحميل.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.

> فحص الوزن في النسخة الأولى مساعد فقط؛ النص العربي غير المشكول لا يسمح بحكم عروضي آلي موثوق في جميع الحالات.

## تدريب الأذن: خمسة أبيات
- اختر فصيحًا أو شعبيًا أو مشتركًا، ودع التطبيق يختار شاعرًا ونصًا من مختارات موثقة.
- تظهر خمسة أبيات كاملة (صدر وعجز) مع اسم الشاعر ورابط المصدر.
- استمع إلى الأبيات تباعًا باستخدام أصوات النطق العربي المتاحة في المتصفح والجهاز، مع ضبط سرعة الصوت وإيقافه.
- اكتب ملاحظتك عن لغة الشاعر، وتُحفظ محليًا ضمن محاولات التدريب.
- المختارات محفوظة داخل التطبيق وتعمل دون اتصال. لا يدّعي التطبيق توليد شعر جديد أو صحة كل رواية شعرية؛ قد توجد فروق نصية بين المصادر.
